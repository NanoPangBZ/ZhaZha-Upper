# 音弦智作(YOUR_WAY_STUDIO) 协议打包格式

本文档描述 YOUR_WAY_STUDIO 通信协议在字节流上的打包/解包格式。

---

## 1. 帧结构概览

一帧数据由 **固定包头（12 字节）** + **可变长度数据区** + **CRC16（2 字节）** 组成。

| 组成部分   | 长度        | 说明 |
|------------|-------------|------|
| 固定包头   | 12 字节     | 魔数、地址、消息 ID、长度、序号、扩展标志、保留 |
| 数据区     | 0 ~ N 字节  | 由包头中的“数据长度”字段指定 |
| CRC16      | 2 字节      | 大端，对“包头+数据区”计算，不含 CRC 自身 |

**单帧最小长度**：12 + 0 + 2 = **14 字节**（无数据）。

---

## 2. 包头字段定义（12 字节）

按传输顺序（字节序均为大端，多字节字段高字节在前）：

| 字节序号 | 字段名         | 长度 | 说明 |
|----------|----------------|------|------|
| 0        | 魔数高字节     | 1    | 固定 `0xAA`，用于帧同步 |
| 1        | 魔数低字节     | 1    | 固定 `0x55` |
| 2        | 发送者 Host ID | 1    | 发送方主机 ID |
| 3        | 目标 Host ID   | 1    | 接收方主机 ID |
| 4        | 消息 ID 高字节 | 1    | 消息 ID 高 8 位 |
| 5        | 消息 ID 低字节 | 1    | 消息 ID 低 8 位 |
| 6        | 数据长度高字节 | 1    | 数据长度高 8 位 |
| 7        | 数据长度低字节 | 1    | 数据长度低 8 位，表示其后“数据区”的字节数 |
| 8        | 序号           | 1    | 包序号，用于应答/去重 |
| 9        | 扩展标志       | 1    | 见下表 |
| 10       | 保留 1         | 1    | 保留，发送时填 0 |
| 11       | 保留 2         | 1    | 保留，发送时填 0 |

### 2.1 扩展标志字节（第 9 字节）

| 位     | 名称        | 说明 |
|--------|-------------|------|
| bit0   | need_ack    | 本消息是否需要对方回复 ACK（1=需要） |
| bit1   | is_ack      | 本消息是否为对某条消息的 ACK（1=是） |
| bit2~5 | forword_cnt | 转发计数（0~15），每经一次转发加 1 |
| bit6~7 | 保留        | 保留，填 0 |

---

## 3. 数据区

- 紧接在 12 字节包头之后。
- 长度由包头中的 **数据长度**（第 6、7 字节，大端 16 位）指定。
- 长度为 0 时，无数据区，下一字节即为 CRC16 高字节。

---

## 4. CRC16 校验

- **算法**：XMODEM（CCITT），即 CRC-16/ACORN。
  - 多项式：0x1021（x^16 + x^12 + x^5 + 1）
  - 初始值：0x0000
  - 不反射输入/输出，不与常数异或。
- **校验范围**：从帧首（0xAA）到数据区最后一个字节，**不包含** CRC 的 2 字节。
- **在帧中的存放**：大端。先 CRC 高字节，再 CRC 低字节。

即：对长度为 `12 + data_len` 的字节序列计算 CRC16，结果按高字节、低字节依次放在数据区之后。

---

## 5. 字节流示例（无数据）

一帧最小包（无数据、无 ACK、序号 0）：

```text
AA 55 01 02 00 00 00 00 00 00 00 00 [CRC16_H] [CRC16_L]
│  │  │  │  │     │     │  │  │
│  │  │  │  │     │     │  │  └─ 扩展标志 = 0
│  │  │  │  │     │     │  └─ seq = 0
│  │  │  │  │     │     └─ data_len = 0
│  │  │  │  │     └─ msg_id = 0
│  │  │  │  └─ target_host_id = 2
│  │  │  └─ sender_host_id = 1
│  │  └─ 魔数 0x55
│  └─ 魔数 0xAA
```
